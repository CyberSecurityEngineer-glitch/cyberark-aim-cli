# CyberArk Rotation Simulator (Concept Project)

A conceptual PAM automation project that demonstrates secure
privileged credential rotation logic on a Linux host.

## What it simulates
- Centralized secret storage (encrypted file)
- Scheduled credential rotation
- Audit logging of every rotation event

## Concepts demonstrated
- Credential rotation
- Centralized policy enforcement
- Auditability

## How to run
\`\`\`bash
chmod +x rotate_secret.sh
./rotate_secret.sh
\`\`\`
